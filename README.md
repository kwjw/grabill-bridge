# Grabill Road over the St. Joseph River: 3D project model

Interactive model of INDOT Contract B-42165-A (Allen County Bridge No. 29, Leo-Cedarville, Indiana), built by an AI system
from the public bid documents. Live: https://kwjw.github.io/grabill-bridge/

Best in a current desktop Chrome, Edge or Safari. Use the Quality menu if it runs slowly. Open "Sources" in the app for
what is exact, simplified, estimated and illustrative. Not for construction.

Third-party material: three.js (MIT), ez-tree (MIT), Inter typeface (OFL), Poly Haven textures and skies (CC0),
USGS 3DEP elevation and USDA NAIP imagery (public domain), State of Indiana orthophotography and building footprints,
INDOT letting plans (public records).
